== Features

* *3x4 Customizable Grid* - Quick access to 12 apps in a clean grid layout
* *Network Status* - Online/offline indicator for the local connection
* *Service Status* - Colored badge on the status button showing the current state reported by https://status.proton.me[status.proton.me]
* *Keyboard Shortcut* - Open the launcher instantly with `Alt+Shift+L`
* *Light and Dark Themes* - Proton's own Snow and Carbon colors, automatic or chosen in the settings
* *Settings Page* - Drag apps to reorder them, hide the ones you do not use and pick a theme; preferences sync across devices through the browser
* *Performance Metrics* - Displays load time in milliseconds
* *Auto-close* - Optionally closes popup after launching an app
* *Background Tabs* - `Ctrl`/`Cmd` + click or middle-click opens an app without leaving the current tab
* *Localized* - English and Brazilian Portuguese, following the browser language
* *Zero Dependencies* - Pure vanilla JavaScript, no external libraries
* *Minimal Permissions* - Only `storage`, which shows no install warning

== Installation

Install it from the https://chromewebstore.google.com/detail/proton-launcher-unofficia/ajniphjinhppblnkeolojgopecjlnecn[Chrome Web Store] (works in Chrome, Brave, Edge and other Chromium browsers).

=== From source

. Download or clone this repository
. In Chrome/Brave, go to `chrome://extensions/` and enable *Developer mode*
. Click "*Load unpacked*" and select the project folder

=== Firefox

Firefox 140 or later is supported, including forks such as Mullvad Browser. To try it from source:

. Go to `about:debugging#/runtime/this-firefox`
. Click "*Load Temporary Add-on*" and select the `manifest.json` file

A temporary add-on is removed when Firefox restarts.

In browsers that always use private browsing, such as Mullvad Browser, the extension only runs after enabling *Run in Private Windows* in `about:addons` → Proton Launcher.

== Shortcuts

[cols="1,2"]
|===
|Shortcut |Action

|`Alt+Shift+L`
|Open the launcher popup

|`Ctrl`/`Cmd` + click, or middle-click
|Open the app in a background tab and keep the popup open
|===

If `Alt+Shift+L` does not open the popup, the browser or another extension already uses it (a suggested shortcut that conflicts is skipped). Set a different one in `chrome://extensions/shortcuts`. Installs from earlier versions, which suggested `Ctrl+Shift+L`, may keep their previous shortcut.

== Configuration

Most users only need the settings page: click the gear icon in the popup, or open the extension's *Options*. There you can reorder apps by dragging, hide apps and choose the theme.

To change the bundled defaults, edit the files in `config/`.

=== settings.json Options

[source,json]
----
{
  "ui": {
    "grid_columns": 3,
    "grid_rows": 4
  },
  "behavior": {
    "close_popup_on_launch": true
  }
}
----

[cols="1,1,2"]
|===
|Option |Default |Description

|`grid_columns`
|`3`
|Number of grid columns

|`grid_rows`
|`4`
|Number of grid rows

|`close_popup_on_launch`
|`true`
|Auto-close popup after opening an app
|===

=== Adding Custom Apps

Edit `config/apps.json` to add or modify apps:

[source,json]
----
{
  "title": "My App",
  "url": "https://example.com",
  "id": "my-app",
  "icon": "/assets/apps/my-app.png",
  "description": "My custom app"
}
----

The `id` must be unique and stable, since saved preferences refer to it. The order of the array is the default grid order. Icons must be bundled under `assets/apps/`: the Content Security Policy blocks remote images. The URL domain must also be in the whitelist of `validateUrl` in `popup/popup.js`.

=== Theme Colors

Light and dark colors are CSS variables in `common/theme.css`, copied from Proton's Snow and Carbon themes.

== Security & Permissions

=== Minimal Permissions

The only permission requested is `storage`, which does not trigger an install warning:

* `chrome.storage.sync` (`storage` permission) - For the settings (app order, hidden apps, theme)
* `chrome.tabs` (no permission needed) - For opening new tabs
* `chrome.commands` (no permission needed) - For keyboard shortcuts

=== Security Features

* *URL Whitelist* - Only allows URLs from approved domains (Proton, SimpleLogin, StandardNotes)
* *HTTPS Only* - All URLs must use HTTPS protocol
* *XSS Protection* - UI is built with DOM APIs and `textContent`, never `innerHTML`
* *Content Security Policy* - Strict CSP preventing inline scripts and remote images; network requests are limited to `status.proton.me`

=== Privacy

The extension collects no data. App icons are bundled in the package. Settings are stored with `chrome.storage.sync`, so the browser syncs them across your devices if browser sync is on; they never leave the browser otherwise. The only request it makes on its own is one anonymous call to the public `https://status.proton.me/api/v2/status.json` endpoint each time the popup opens, without cookies, to color the service status badge. Any other traffic only happens when you click an app or link, which opens that site in a new tab.
