== Features

* *3x3 Customizable Grid* - Quick access to 9 apps in a clean grid layout
* *Network Status* - Online/offline indicator for the local connection
* *Service Status* - Colored badge on the status button showing the current state reported by https://status.proton.me[status.proton.me]
* *Keyboard Shortcut* - Open the launcher instantly with `Ctrl+Shift+L`
* *Theme Support* - Modern gradient theme with customization options
* *Performance Metrics* - Displays load time in milliseconds
* *Auto-close* - Optionally closes popup after launching an app
* *Background Tabs* - `Ctrl`/`Cmd` + click or middle-click opens an app without leaving the current tab
* *Localized* - English and Brazilian Portuguese, following the browser language
* *Zero Dependencies* - Pure vanilla JavaScript, no external libraries
* *Minimal Permissions* - Privacy-focused with no special permissions required

== Installation

Install it from the https://chromewebstore.google.com/detail/proton-launcher-unofficia/ajniphjinhppblnkeolojgopecjlnecn[Chrome Web Store] (works in Chrome, Brave, Edge and other Chromium browsers).

=== From source

. Download or clone this repository
. In Chrome/Brave, go to `chrome://extensions/` and enable *Developer mode*
. Click "*Load unpacked*" and select the project folder

== Shortcuts

[cols="1,2"]
|===
|Shortcut |Action

|`Ctrl+Shift+L`
|Open the launcher popup

|`Ctrl`/`Cmd` + click, or middle-click
|Open the app in a background tab and keep the popup open
|===

If `Ctrl+Shift+L` does not open the popup, another extension already uses it (browsers skip a suggested shortcut that conflicts). Set a different one in `chrome://extensions/shortcuts`.

== Configuration

Edit the files in `config/` to customize apps and preferences.

=== settings.json Options

[source,json]
----
{
  "ui": {
    "theme": "gradient",
    "grid_size": 3
  },
  "behavior": {
    "close_popup_on_launch": true
  }
}
----

[cols="1,1,2"]
|===
|Option |Default |Description

|`theme`
|`"gradient"`
|Active theme name

|`grid_size`
|`3`
|Grid dimensions (3 = 3x3 grid)

|`close_popup_on_launch`
|`true`
|Auto-close popup after opening an app
|===

=== Adding Custom Apps

Edit `config/apps.json` to add or modify apps:

[source,json]
----
{
  "title": "My App",
  "url": "https://example.com",
  "icon": "/assets/apps/my-app.png",
  "position": 0,
  "description": "My custom app"
}
----

Icons must be bundled under `assets/apps/`: the Content Security Policy blocks remote images.

=== Creating Custom Themes

Add new themes in `config/settings.json`:

[source,json]
----
{
  "themes": {
    "my-theme": {
      "background": "linear-gradient(135deg, #1a1a2e 0%, #16213e 100%)"
    }
  }
}
----

== Security & Permissions

=== Minimal Permissions

This extension operates with *zero explicit permissions*. It only uses:

* `chrome.tabs` - For opening new tabs
* `chrome.commands` - For keyboard shortcuts

=== Security Features

* *URL Whitelist* - Only allows URLs from approved domains (Proton, SimpleLogin, StandardNotes)
* *HTTPS Only* - All URLs must use HTTPS protocol
* *XSS Protection* - UI is built with DOM APIs and `textContent`, never `innerHTML`
* *Content Security Policy* - Strict CSP preventing inline scripts and remote images; network requests are limited to `status.proton.me`

=== Privacy

The extension collects no data. App icons are bundled in the package. The only request it makes on its own is one anonymous call to the public `https://status.proton.me/api/v2/status.json` endpoint each time the popup opens, without cookies, to color the service status badge. Any other traffic only happens when you click an app or link, which opens that site in a new tab.
